# Sample Videos

Place any test video files here to easily upload them via the Streamlit interface.

## Suggested Sources

- [Pexels Free Stock Video](https://www.pexels.com/videos/) — search "traffic", "crowd", "street"
- [Pixabay Videos](https://pixabay.com/videos/) — free, no attribution required
- [Sample-Videos.com](https://www.sample-videos.com/) — direct MP4 downloads

## Recommended Test Scenarios

| Scenario              | What to test                     |
|-----------------------|----------------------------------|
| Street / traffic      | Vehicle tracking, ID consistency |
| Crowd / pedestrians   | Person multi-tracking            |
| Parking lot           | Stationary + moving objects      |
| Hallway / corridor    | Occlusion handling               |


## Supported Formats

`.mp4`, `.avi`, `.mov`, `.mkv`, `.wmv`, `.webm`, `.m4v`
